## 핵심 연구·제품 질문

> 같은 인물과 사건이 정사와 연의에서 어떻게 다르게 표현되며, 그 차이를 재현 가능한 코드·네트워크·설명 가능한 게임 점수로 어떻게 탐색하게 할 것인가?

## 데이터 계층

```text
Source document/edition
  → Evidence span
  → Claim with source layer
  → Coded action/relationship
  → Entity/event graph
  → Analysis metric
  → Versioned game score + confidence
  → UI explanation / grounded AI answer
```

## 권장 첫 vertical slice

한 사건을 고르고 인물 3~5명만 다룹니다.

- 후보: 관도대전(리더십·전략·인재 활용) 또는 적벽대전(출처 차이·연합 네트워크)
- 정사/주석/연의에서 근거 구절 20~40개
- 행동 코드 5~8개
- 구성 지표 1개: 예) `Strategic Leadership`
- 네트워크 1개: 인물-관계 typed graph
- 게임 루프 1개: 근거를 보고 가중치를 조정해 나만의 점수 만들기
- 화면 1개: 사건 비교 대시보드 + AI “정사/연의/비교” 질문

## Candidate product loop

아래 루프는 Explorer/Hybrid 가설의 후보이며 아직 승인된 요구사항이 아닙니다.

1. 사용자가 사건 또는 인물을 고른다.
2. 정사/연의 차이를 예측한다.
3. 근거 카드와 코드 라벨을 확인한다.
4. 기본 점수의 구성과 신뢰도를 본다.
5. 가중치를 바꾸고 순위 변화 이유를 확인한다.
6. 반대 근거까지 확인하면 탐구 배지를 얻는다.

## 아직 결정해야 할 것

- 사용할 정사·주석·연의 판본과 번역 정책
- 외부 게임 수치/브랜드를 실제 제품에 포함할지 여부
- 한국어 중심인지 한문/중문 원문 병기인지
- 기본 능력치 체계와 가중치 승인 절차
- 퀘스트가 개인 플레이인지 커뮤니티 비교까지 포함하는지
