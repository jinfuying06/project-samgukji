# Three Kingdoms Domain Override

이 문서는 모든 역할에 적용됩니다. 일반 역할 지침과 충돌하면 더 엄격한 이 문서를 따릅니다.

## 제품 정체성

이 프로젝트는 “역사적 진실을 점수로 확정하는 앱”이 아니라 **정사·주석·연의의 차이를 탐색하고, 명시적 코딩 규칙으로 만든 해석적 지표를 게임처럼 실험하는 디지털 인문학 데이터 제품**입니다.

## 출처 층위

모든 근거는 다음 중 하나로 분류하고 UI까지 유지합니다.

1. `HISTORY_BASE`: 정사 본문
2. `HISTORY_ANNOTATION`: 배송지주 등 주석/인용 사료
3. `ROMANCE`: 《삼국지연의》
4. `LATER_INTERPRETATION`: 현대 연구·후대 해석
5. `GAME_DATA`: 게임 능력치/시스템

서로 다른 층위의 충돌은 오류가 아니라 비교 대상입니다. `HISTORY_BASE`와 `ROMANCE`를 하나의 사실로 병합하지 않습니다.

## 출처와 인용

- evidence span마다 작품, 권/회/장, 판본, 언어, 번역자, 위치, URL/식별자, 접근일을 가능한 범위에서 기록합니다.
- 원문 인용, 제공된 번역, 자체 번역, 의역을 구분합니다.
- 저작권이 불명확한 현대 번역문은 장문 저장/노출하지 않고 위치 참조와 허용된 짧은 발췌 또는 자체 요약을 사용합니다.
- 첨부 대화에서 제안된 논문은 검증 전 후보이며 실제 존재·메타데이터·내용을 확인하기 전 근거로 쓰지 않습니다.

## 엔터티 정합성

- 인물은 canonical ID를 사용하고 한자명, 한국어명, 자(字), 호칭, 시호, 이명, 표기 변형을 alias로 둡니다.
- 동일 이름/번역명이 다른 인물을 가리키는 경우 합치지 않습니다.
- 사건·전투는 시작/종료 시점의 불확실성, 위치, 참여 역할, 결과, source layer를 가집니다.
- 주장 단위와 사건 단위를 분리합니다. 한 구절이 곧 하나의 역사적 사실이라고 가정하지 않습니다.

## 텍스트 코딩

- 코드북은 라벨 정의, 포함/제외 예시, 강도, 행위자/대상, 부정/풍자/간접화법, 모호성 처리 규칙을 포함합니다.
- 빈도만으로 능력치를 만들지 않습니다. 텍스트 길이, 등장 기회, 저자/장르 편향을 고려합니다.
- 최초 표본은 최소 두 코더가 독립 코딩하고, 합치도와 adjudication 기록을 남깁니다.
- LLM 자동 코딩은 사람 golden set과 비교한 뒤 보조 수단으로만 사용합니다.
- 인물의 성격, 지능, 정신 상태를 사료만으로 임상적 사실처럼 진단하지 않습니다.

## 점수와 비교

- 점수는 `관측 근거 → 코드 → 하위 지표 → 정규화 → 가중치 → 표시 점수`의 전체 경로를 공개합니다.
- 점수에는 버전, source mode, 포함 사건, 데이터 커버리지, 불확실성/신뢰도를 붙입니다.
- 기록이 적다는 이유로 낮은 능력치를 주지 않습니다. 결측은 0이 아닙니다.
- 정사 점수, 연의 점수, 게임 수치는 나란히 비교할 수 있으나 합성 점수는 명시적 opt-in과 공식이 필요합니다.
- 순위는 표본/가중치/기간 변경에 민감하므로 안정성 분석 없이 “최강”으로 표현하지 않습니다.

## 네트워크 분석

- edge는 방향, 관계 유형, 시작/종료, 사건, source layer, confidence를 가집니다.
- 공동 등장과 실제 상호작용을 구분합니다.
- centrality는 인기도나 능력의 직접 측정치가 아닙니다.
- 정사와 연의 네트워크는 먼저 따로 계산한 뒤 비교합니다.

## LLM 답변 모드

- `정사`: HISTORY_BASE/HISTORY_ANNOTATION만 사용
- `연의`: ROMANCE만 사용하고 허구/문학 층위를 표시
- `비교`: 출처별 일치·차이·침묵을 병렬 제시
- `게임`: GAME_DATA의 규칙/수치와 역사 근거를 구분

모든 주요 답변은 evidence ID를 포함하고, 근거 부족 시 답변을 보류합니다.

## 게이미피케이션 가드레일

- 퀘스트와 배지는 사용자가 근거를 더 보게 만들어야지 클릭이나 확신을 과장하게 만들면 안 됩니다.
- 보상 대상 예: 출처 비교 완료, 반대 근거 확인, 점수 공식 열기, 자신만의 가중치 실험, 퀴즈 후 근거 확인.
- 금지/주의 대상: 역사 왜곡을 유도하는 streak, 확률형 보상, 과도한 경쟁 순위, 근거 없는 “정답 인물”, 인기 인물 편향 보상.
- 사용자의 커스텀 점수와 프로젝트 기본 점수를 명확히 구분하고 공유 화면에 공식/버전을 표시합니다.

## 도메인 Gate hard blockers

- 정사/연의 source layer 혼합
- 존재하지 않거나 위치를 확인할 수 없는 인용
- alias 충돌로 다른 인물 병합
- 결측을 0으로 점수화
- 점수 공식 또는 구성 근거 비공개
- unsupported LLM claim
- 허가되지 않은 번역/게임 자산의 배포
- 사람 합의도 검증 없는 LLM 자동 코딩의 본 데이터 반영
