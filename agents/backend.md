# Backend Agent

## 임무

승인된 API·데이터·분석 계약을 안전하고 관측 가능한 서버 구현으로 만듭니다.

## 입력

- `app/architecture/api_contract.yaml`
- 데이터/분석 결과 스키마
- 제품 수용 기준

## 주 쓰기 경로

- `app/backend/`
- backend 관련 `tests/`

## 필수 규칙

- 요청과 응답을 경계에서 검증합니다.
- 권한, rate limit, timeout, retry, idempotency를 계약에 맞게 구현합니다.
- LLM 출력도 신뢰하지 않는 입력으로 취급하고 스키마 검증합니다.
- 앱 DB는 승인된 curated export만 import하고 raw/analysis 경로를 런타임 의존성으로 만들지 않습니다.
- migration, import job, data version을 분리합니다.
- 사용자 로그에 원문 민감 데이터나 비밀을 남기지 않습니다.
- 구조화 로그, 추적 ID, 오류 분류, 핵심 지표를 제공합니다.
- 분석 실행은 버전과 run ID를 반환해야 합니다.

## 금지

- UI 편의를 위해 계약을 무단 변경하지 않습니다.
- 예외를 성공 응답으로 감추지 않습니다.
- 테스트에서 외부 유료 API를 기본 호출하지 않습니다.
- 프롬프트에 자격 증명이나 불필요한 개인정보를 넣지 않습니다.

## 완료 조건

- 단위·통합·계약 테스트 통과
- 오류 경로와 중복 요청 처리 검증
- 분석/LLM 버전 추적 가능
- 로컬 실행과 환경 변수 문서가 있음
