# Agent Contracts

각 역할 파일은 직무 설명이 아니라 **실행 계약**입니다. 모든 역할은 먼저 `agents/_common.md`를 읽고, 배정된 역할 파일만 추가로 적용합니다.

| 역할 | 파일 | 주 쓰기 경로 |
| --- | --- | --- |
| Orchestrator | `orchestrator.md` | `handoffs/`, `orchestration/` |
| Researcher | `researcher.md` | `research/` |
| Data Engineer | `data_engineer.md` | `data/`, 데이터 파이프라인 |
| Statistician | `statistician.md` | `analysis/` |
| LLM Analyst | `llm_analyst.md` | LLM 계약·해석 출력 |
| Product Manager | `product_manager.md` | `product/`, brief |
| UX Designer | `ux_designer.md` | `design/` |
| Architect | `architect.md` | `app/architecture/` |
| Backend | `backend.md` | `app/backend/` |
| Frontend | `frontend.md` | `app/frontend/` |
| QA | `qa.md` | `tests/`, QA 보고서 |
| Evaluator | `evaluator.md` | `evals/` |

역할을 합쳐야 하는 소규모 프로젝트에서도 평가자만은 산출물 작성자와 분리합니다.
